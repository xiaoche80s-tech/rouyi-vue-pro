# 经销商管理客服 SaaS 平台 — 产品需求文档（PRD）

> **版本**: V2.0 | **文档来源**: 基于交互原型自动提取生成  
> **产品定位**: 面向医疗器械品牌商的经销商全生命周期管理 + AI 智能客服 SaaS 平台

---

## 一、产品概述

### 1.1 产品背景

品牌商（医疗器械厂商）需要对下游经销商进行全生命周期管理，涵盖合同签约、政策执行、订单流转、售后处理、文件合规和客户服务六大场景。当前依赖人工和 Excel 管理，效率低、数据不透明、客服响应慢。

### 1.2 产品目标

| 目标 | 衡量指标 |
|------|---------|
| 经销商管理数字化 | 合同/订单/售后全流程线上化 |
| 政策执行可视化 | 8大KPI指标按季度追踪达成率 |
| 客服智能化 | AI 客服自动响应 + 人工客服兜底 |
| 多角色协同 | 管理员/经销商/执行员三级权限体系 |

### 1.3 用户角色

| 角色 | 身份 | 数据范围 | 核心场景 |
|------|------|---------|---------|
| **🛡️ 品牌商管理员** | 平台管理员 | 全量数据（所有经销商） | 全局监控、策略制定、合同下发 |
| **🏥 经销商** | 经销商管理员 | 仅本公司数据 | 查看合同、下单、申请售后、咨询 |
| **🔧 服务单执行员** | 品牌商内部执行人员 | 负责范围内经销商的全量数据 | 工单处理、售后执行、任务跟进 |

### 模块一：签约进度

#### 3.1.1 功能概述
管理品牌商与经销商之间的合同签署全流程，包括主合同、政策合同、补充协议、终止协议四种类型。

#### 3.1.2 筛选器

| 筛选器 | 类型 | 选项 |
|--------|------|------|
| 时间-周期 | 单选 | 按月 / 按季度 / 按年 |
| 月份 | 多选 | 1月~12月 |
| 年度 | 下拉 | 年度列表 |
| 产品线 | 下拉 | 骨科 / 心内科 / 外科 / 神经外科 |
| 合同类型 | 下拉 | 主合同 / 政策合同 / 补充协议 / 终止协议 |
| 状态 | 下拉 | 已签署 / 未签署 |
| 经销商 | 下拉 | 8家经销商 |

#### 3.1.3 统计卡片（6张）

| 卡片 | 指标 | 子指标 |
|------|------|--------|
| 合同总数 | 总合同数 | 含主合同·政策合同·补充·终止 |
| 已签署 | 数量 + 占比% | — |
| 未签署 | 数量 | 待签署数 · 签署中数 |
| 主合同 | 总数 | 已签署 / 未签署 |
| 政策合同 | 总数 | 已签署 / 未签署 |
| 补充协议 | 总数 | 已签署 / 未签署 |
| 终止协议 | 总数 | 已签署 / 未签署 |

#### 3.1.4 合同列表

**表格列**: 经销商 | 合同类型 | 合同编码 | 合同名称 | 状态 | 下发时间 | 签署日期 | 操作

**合同编码规则**:
- `MC-{年份}-{序号}` — 主合同
- `POL-{年份}-{序号}` — 政策合同
- `SA-{年份}-{序号}` — 补充协议
- `TA-{年份}-{序号}` — 终止协议

**操作按钮**:
| 状态 | 可用操作 |
|------|---------|
| 已签署 | 📎 附件（预览/下载）、💬 咨询 |
| 未签署 | 去签署、📎 附件、💬 咨询 |

**批量操作**: 批量申请盖章、批量咨询服务

#### 3.1.5 图表 — 合同签约趋势

- **类型**: 堆叠柱状图（Stacked Bar Chart）
- **维度**: 按月度展示 4 种合同类型的累计数量
- **交互**: 点击柱子查看当月各类合同明细

#### 3.1.6 弹窗交互

| 弹窗 | 触发 | 内容 |
|------|------|------|
| 跳转签约平台 | 点击"去签署" | 显示合同编号，提示电子签章平台对接为二期功能 |
| 附件弹出层 | 点击"📎 附件" | 文件名、大小、页数，提供预览/下载 |
| 签约咨询 | 点击"💬 咨询" | AI 智能客服聊天窗口，自动关联合同上下文 |

#### 3.1.7 业务规则

1. 电子签章（法大大/上上签/e签宝）为**二期功能**，一期手动更新签署状态
2. 合同附件为 PDF 格式，支持在线预览和下载
3. 批量盖章需先选择合同，否则提示"请先选择"

### 模块二：政策看板

#### 3.2.1 功能概述
以多维度 KPI 仪表盘形式展示经销商政策执行情况，支持从指标→目标→政策的三级数据钻取。

#### 3.2.2 筛选器

| 筛选器 | 类型 | 选项 |
|--------|------|------|
| 政策类型 | 多选 | 返利 / 促销 / 其他 |
| 指标类型 | 多选 | 8 种指标（见下方） |
| 季度 | 多选 | Q1 / Q2 / Q3 / Q4 |
| 月度 | 多选 | 1月~12月 |
| 产品线 | 多选 | 骨科 / 心内科 / 外科 / 神经外科 |
| 经销商 | 多选 | 8 家经销商 |
| 政策编码 | 文本 | 如 POL-2026-001 |

#### 3.2.3 8 大 KPI 指标面板

每个面板结构：**标题 + 关联政策数 + 季度仪表盘（Q1-Q4）+ 目标分布列表**

| # | 指标 | 单位 | 说明 |
|---|------|------|------|
| 1 | 骨科关节销量 | 件 | 骨科关节类产品季度销售达成 |
| 2 | 市场费用额度 | 万元 | 市场推广费用使用情况 |
| 3 | 战略医院数量 | 家 | 战略级合作医院覆盖数 |
| 4 | 重点医院覆盖 | 家 | 重点目标医院覆盖数 |
| 5 | 植入台数 | 台 | 医疗器械植入手术台数 |
| 6 | 商采金额 | 万元 | 商业采购金额 |
| 7 | 新品推广覆盖 | 家 | 新产品推广覆盖的医院/经销商数 |
| 8 | 重点产品销量 | 件 | 重点推广产品的销售达成 |

**每个季度仪表盘显示**:
- 达成值 / 满点目标值
- 达成率百分比
- 颜色标识：≥100% 绿色达标，<100% 红色预警

#### 3.2.4 数据钻取

**三级钻取路径**: 指标面板 → 目标分布列表 → 政策详情卡片

- **目标分布列表**: 降序/升序排列，展示各目标值及其关联政策数量
- **钻取弹窗**: 展示政策编码、类型、名称、目标值、达成值、执行期间、状态、关联经销商

#### 3.2.5 业务规则

1. 每个指标关联多条政策，每条政策按 Q1-Q4 分解目标
2. 政策类型分三种：返利、促销、其他
3. 达成率低于预设阈值需高亮预警

### 模块三：售后模块

#### 3.3.1 功能概述
管理经销商退货、退换货、退货退款等售后全流程，支持进度节点追踪和 AI 客服集成。

#### 3.3.2 KPI 统计卡片（可点击筛选）

| 卡片 | 说明 |
|------|------|
| 售后订单总数 | 全部售后单数量 |
| 退款 | 含退款的售后单数量 |
| 退货 | 含退货的售后单数量 |
| 已完成 | 数量 + 占比% |
| 未完成 | 处理中的售后单数量 |

#### 3.3.3 筛选器

| 筛选器 | 选项 |
|--------|------|
| 售后类型 | 9 种组合（见下方类型矩阵） |
| 进度 | 已完成 / 进行中 / 换货中 / 待处理 |
| 产品线 | 骨科 / 心内科 / 外科 / 神经外科 |
| 经销商 | 8 家经销商 |
| 搜索 | 售后单号 / 关联订单 |

#### 3.3.4 售后类型矩阵

| 处理方式 \ 原因 | 投诉 | 召回 | 破损 |
|----------------|------|------|------|
| **退货** | 退货-投诉 | 退货-召回 | 退货-破损 |
| **退换货** | 退换货-投诉 | 退换货-召回 | 退换货-破损 |
| **退货退款** | 退货退款-投诉 | 退货退款-召回 | 退货退款-破损 |

#### 3.3.5 售后单列表

**表格列**: 经销商 | 售后单号 | 关联订单 | 时间 | 类型 | 产品 | 当前进度 | 进度详情 | 操作

**售后单号规则**: `SO{YYYYMMDD}-{序号}`

#### 3.3.6 售后流程（进度节点追踪）

**退货/退货退款流程（5步）**:
```
申请提交 → 审核通过 → 商品退回 → [退款完成] → [红字发票]
```

**退换货流程（5步）**:
```
申请提交 → 审核通过 → 问题商品退回 → 新商品发出 → 确认收货
```

- 每个节点显示完成状态（✅ 已完成 / ⏳ 待完成）
- 物流信息：换货发出时显示物流公司和单号（如顺丰 SF533374）
- 退货退款额外包含退款和红字发票步骤

#### 3.3.7 操作

- 每行: 💬 客服（打开 AI 售后咨询）
- 批量: 💬 批量咨询服务

#### 3.3.8 业务规则

1. 退款 + 退货计数存在交叉（退货退款同时计入两类）
2. 红字发票处理符合中国增值税发票管理规范
3. 换货流程集成物流追踪（顺丰等快递单号）

#### 3.4.2 KPI 统计卡片

| 卡片 | 说明 |
|------|------|
| 订单总量 | 全部订单数量 |
| 已完成 | 已完成订单数 |
| 已付款 | 已付款订单数 |
| 未付款 | 未付款订单数 |
| 已开票 | 已开票订单数 |
| 未开票 | 未开票订单数 |

#### 3.4.3 筛选器

**时间快捷筛选**: 今日 / 本周 / 本月 / 全部

| 筛选器 | 类型 | 选项 |
|--------|------|------|
| 季度 | 多选 | Q1~Q4 |
| 月度 | 多选 | 1月~12月 |
| 产品线 | 多选 | 骨科 / 心内科 / 外科 / 神经外科 |
| 经销商 | 多选 | 8 家经销商 |
| 进度 | 下拉 | 待确认 / 已确认 / 已发货 / 已签收 / 已完成 |
| 付款 | 下拉 | 未付款 / 已付款 |
| 开票 | 下拉 | 未开票 / 已开票 / 部分开票 |

#### 3.4.4 订单列表

**表格列**: 订单号 | 经销商 | 产品线 | 金额 | 订单时间 | 付款 | 开票 | 进度 | 操作

**订单号规则**: `ORD-{年份}-{月份}-{序号}`

**汇总信息**: 共 N 条订单，汇总金额 ¥X

#### 3.4.5 订单生命周期

```
待确认 → 已确认 → 已发货 → 已签收 → 已完成
```

**付款流程（独立于订单进度）**: 未付款 → 已付款  
**开票流程（独立于订单进度）**: 未开票 → 部分开票 → 已开票

#### 3.4.6 行操作按钮（条件显示）

| 按钮 | 显示条件 | 点击行为 |
|------|---------|---------|
| 申请付款 | 付款=未付款 | 提交付款申请，预计3个工作日审批 |
| 申请开票 | 开票=未开票或部分开票 | 弹出开票申请表单 |
| 申请退货 | 已付款 且 已签收/已完成 | 提交退货申请 |
| 💬 客服 | 始终显示 | 打开 AI 订单咨询 |

#### 3.4.7 申请开票弹窗

| 字段 | 类型 | 必填 |
|------|------|------|
| 发票抬头 | 单行文本 | 是 |
| 税号（纳税人识别号） | 单行文本 | 是 |
| 特殊开票需求 | 多行文本 | 否 |

#### 3.4.8 批量操作

批量申请付款、批量申请开票、批量申请退货、💬 联系客服

#### 3.4.9 业务规则

1. 付款和开票是两个独立流程，可交叉进行
2. 大额订单支持分批开票（部分开票状态）
3. 退货前置条件：必须先完成付款且已签收/已完成
4. 付款申请提交后需 3 个工作日审批

### 模块五：基础数据

#### 3.5.1 功能概述
集中管理经销商相关的4大类文件（资质、授权、合同、产品），支持查看、AI 解读、下载、盖章申请。

#### 3.5.2 文件分类体系

| 分类 | 子类型 | 编号前缀 |
|------|--------|---------|
| 📜 **资质文件** | 营业执照、经营许可证、备案凭证、质量体系认证 | BL/JYXK/BA/QMS |
| 📋 **授权文件** | 品牌授权书、区域代理授权、产品线授权 | SQ |
| 📝 **合同文件** | 主合同、政策合同、补充协议、终止协议 | MC/POL/SA/TA |
| 📦 **产品文件** | 注册证、合格证、说明书、技术文件、检测报告 | ZCZ/HGZ/SMS/JS/JCBG |

#### 3.5.3 表格结构（4 类统一）

**列**: 文件名称 | 文件编号 | 类型 | 经销商 | 有效期至 | 状态 | 操作

**状态**: 有效 / 即将到期 / 已过期

#### 3.5.4 筛选器

| 筛选器 | 选项 |
|--------|------|
| 文件分类 | 资质文件 / 授权文件 / 合同文件 / 产品文件 |
| 状态 | 有效 / 即将到期 / 已过期 |
| 经销商 | 8 家经销商 |
| 搜索文件名 | 文本实时搜索 |

#### 3.5.5 操作按钮

| 按钮 | 行为 |
|------|------|
| 查看明细 | 弹窗显示文件完整信息（名称/编号/分类/类型/经销商/有效期/状态） |
| 解读 | AI 智能解读弹窗（OCR+NLP 提取关键字段） |
| 下载 | 下载 PDF 文件 |
| 申请盖章 | 提交盖章申请（加盖公章），预计1个工作日完成 |

**批量操作**: 批量下载、批量申请盖章、批量申请客服

#### 3.5.6 AI 解读功能

- **资质文件**: OCR 提取统一社会信用代码、法定代表人、注册资本、成立日期、经营范围、有效期
- **合同文件**: NLP 提取关键条款（标注为二期上线）
- 底部提示："AI 解读功能基于 OCR+NLP 技术自动提取关键字段，结果仅供参考"

#### 3.5.7 业务规则

1. 文件有效期自动监控，即将到期和已过期文件高亮提示
2. 当前版本无文件上传功能，仅支持查看和管理
3. 文件明细弹窗内可直接切换到 AI 解读视图

### 模块六：客户服务

#### 3.6.1 功能概述
客服工作台，集成工单管理和 AI 智能客服，支持咨询→任务的闭环。

#### 3.6.2 6 大咨询分类入口

| 分类 | 图标 |
|------|------|
| 签约咨询 | 📝 |
| 政策咨询 | 📊 |
| 售后咨询 | 🔄 |
| 订单咨询 | 📦 |
| 数据咨询 | 📁 |
| 其他咨询 | 💬 |

点击分类卡片直接打开对应类型的 AI 聊天窗口。

#### 3.6.3 工单/任务列表

**筛选**: 全部工单 / 我创建的 / 我处理的

**表格列**: 任务编号 | 任务内容 | 紧急程度 | SLA | 状态 | 创建时间 | 操作

**任务编号规则**: `TASK-{YYYYMMDD}-{序号}`

#### 3.6.4 任务紧急程度与 SLA

| 紧急程度 | 标识 | SLA 时效 |
|---------|------|---------|
| 紧急 | 🔴 | 24 小时 |
| 普通 | 🟡 | 48 小时 |
| 特殊要求 | 🔵 | 按备注协商 |

**任务状态**: 已指派 / 处理中 / 已完成

#### 3.6.5 下发新任务弹窗

| 字段 | 类型 | 说明 |
|------|------|------|
| 任务内容 | 单行文本 | 必填 |
| 紧急程度 | 单选 | 🔴紧急 / 🟡普通 / 🔵特殊要求 |
| 特殊备注 | 多行文本 | 可选 |

提交后自动生成任务编号，SLA 倒计时开始，超时自动升级通知。

#### 3.6.6 AI 智能客服

**触发方式**:
- 右下角浮动 💬 按钮
- 各模块行内 💬 咨询按钮
- 客户服务模块分类卡片

**聊天窗口功能**:
- 上下文感知：自动关联当前操作对象（如合同编号、售后单号）
- AI 自动回复：模拟智能应答
- 👤 转人工客服：转接真人客服（如"张经理"）
- 📋 下发任务：聊天中直接创建工单

#### 3.6.7 业务规则

1. AI 客服优先接待，不满意可转人工
2. 聊天中可直接下发任务，实现咨询→工单闭环
3. SLA 超时自动升级通知管理层
4. 催办功能向处理人发送催办通知

### 附录 B：状态流转汇总

**合同状态**: 未签署 → 已签署

**订单进度**: 待确认 → 已确认 → 已发货 → 已签收 → 已完成

**订单付款**: 未付款 → 已付款

**订单开票**: 未开票 → 部分开票 → 已开票

**售后进度（退货/退货退款）**: 申请提交 → 审核通过 → 商品退回 → 退款完成 → 红字发票

**售后进度（退换货）**: 申请提交 → 审核通过 → 问题商品退回 → 新商品发出 → 确认收货

**售后状态**: 待处理 → 进行中 / 换货中 → 已完成

**工单状态**: 已指派 → 处理中 → 已完成

**文件状态**: 有效 → 即将到期 → 已过期
