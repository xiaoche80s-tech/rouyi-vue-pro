- **自动配置层**：`YudaoWebSocketAutoConfiguration` 作为入口，根据 `yudao.websocket.sender-type` 属性动态装配 Local、Redis、Kafka、RabbitMQ 或 RocketMQ 发送器。
- **核心处理层**：`JsonWebSocketMessageHandler` 负责解析 JSON 格式的消息帧（`JsonWebSocketMessage`），并根据 `type` 字段分发给对应的 `WebSocketMessageListener`。
- **会话管理层**：`WebSocketSessionManager` 维护用户 ID、租户 ID 与 `WebSocketSession` 的映射关系，支持按用户或租户维度检索会话。
- **安全拦截层**：`LoginUserHandshakeInterceptor` 在握手阶段提取并注入登录用户信息，确保后续业务逻辑可获取当前上下文。
- **发送抽象层**：`AbstractWebSocketMessageSender` 统一处理消息序列化与会话遍历，具体传输协议由子类（如 `RedisWebSocketMessageSender`）实现。
