- 入口与自动化配置：通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册 `YudaoDictAutoConfiguration`，在 Spring Boot 启动时初始化 `DictFrameworkUtils`（依赖 `DictDataCommonApi`）。
- Excel 核心层：`excel.core.util.ExcelUtils` 封装写/读接口；写操作链式注册 `ColumnWidthMatchStyleStrategy`、`SelectSheetWriteHandler` 与 `LongStringConverter`；读操作直接调用 FastExcel 同步读取。
- 下拉框处理：`SelectSheetWriteHandler` 解析头类字段上的 `@ExcelColumnSelect`，按 dictType 或 functionName 收集选项，并在首个 Sheet 写入时创建/复用“字典sheet”，通过 Named Range + DataValidation 实现单元格下拉。
- 字典转换与校验：`DictConvert` 结合 `@DictFormat` 完成 Excel 单元格值与字典 label/value 的双向转换；`InDict`/`InDictValidator`/`InDictCollectionValidator` 提供单值与集合的字典值合法性校验。
- 依赖方向：Excel 工具依赖 FastExcel 与 Servlet API（provided），字典模块依赖通用业务 API（system.dict.DictDataCommonApi），两者通过 `DictFrameworkUtils` 解耦。
