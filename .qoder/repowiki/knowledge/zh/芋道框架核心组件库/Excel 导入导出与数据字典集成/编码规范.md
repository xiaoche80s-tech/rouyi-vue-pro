- Excel 写操作统一关闭自动流关闭（autoCloseStream(false)），由 Servlet 容器管理响应流生命周期。
- Long 类型导出统一注册 LongStringConverter，避免前端展示丢失精度。
- 下拉列定义采用注解驱动：字段需同时具备 @ExcelProperty（确定列索引）与 @ExcelColumnSelect（指定 dictType 或 functionName）。
- 字典相关功能集中通过 DictFrameworkUtils 访问，避免在各转换器/校验器中直接注入 API Bean。
- 校验器对 null/空集合采取“跳过校验”策略，仅在非空时执行字典值匹配并自定义错误模板。
