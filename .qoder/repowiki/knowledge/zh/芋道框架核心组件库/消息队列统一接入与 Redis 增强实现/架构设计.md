- 入口与自动装配：通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册三个自动配置类；RabbitMQ 侧以 `@ConditionalOnClass` 仅在存在 `RabbitTemplate` 时生效，Redis 侧以 `after = YudaoRedisAutoConfiguration` 保证依赖顺序。
- 分层结构：`rabbitmq/config` 仅负责 RabbitMQ 的 Bean 定义；`redis/config` 分为生产者/消费者自动配置；`redis/core` 提供统一模板 `RedisMQTemplate`、消息基类与两类监听抽象（Pub/Sub、Stream），以及拦截器接口与定时任务。
- 依赖方向：Redis MQ 强依赖 `yudao-spring-boot-starter-redis`；Kafka/RocketMQ 依赖在 `pom.xml` 中标记为 `optional=true` 且当前模块未提供对应自动配置，体现“按需引入、不强制绑定”的边界。
- 关键接口边界：`RedisMQTemplate` 作为生产端统一入口；消费端通过 `AbstractRedisChannelMessageListener` 与 `AbstractRedisStreamMessageListener` 抽象泛型消息类型与生命周期钩子；`RedisMessageInterceptor` 形成横切扩展点。
- 可靠性与运维：消费者容器在 `YudaoRedisMQConsumerAutoConfiguration` 中集中装配，Stream 场景启用手动 ack、错误不取消消费，并提供 `RedisPendingMessageResendJob` 与 `RedisStreamMessageCleanupJob` 两个定时任务进行重投与清理。
