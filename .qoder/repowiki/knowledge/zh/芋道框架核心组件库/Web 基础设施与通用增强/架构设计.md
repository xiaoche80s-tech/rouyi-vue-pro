- 采用 Spring Boot Starter 模式，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 自动装配各功能模块。
- 模块化设计：内部划分为 apilog（日志）、desensitize（脱敏）、encrypt（加密）、xss（防护）、swagger（文档）、web（核心配置与异常处理）等子包，各模块通过 AutoConfiguration 独立生效。
- 核心机制：利用 Filter 链（如 ApiAccessLogFilter, ApiEncryptFilter, XssFilter）和 HandlerInterceptor 实现请求预处理；通过 `@RestControllerAdvice` 实现全局异常统一收口与标准化返回。
- 扩展点：提供 `@ApiAccessLog`、`@ApiEncrypt` 及各类脱敏注解（如 `@MobileDesensitize`），结合 Jackson 序列化器或 AOP 实现声明式功能增强。
