- **自动装配层**：通过 `YudaoSecurityAutoConfiguration` 和 `YudaoWebSecurityConfigurerAdapter` 完成 Spring Security 核心组件（如 `PasswordEncoder`、`AuthenticationEntryPoint`）的注册与安全过滤链配置。
- **认证与授权层**：`TokenAuthenticationFilter` 负责拦截请求并调用远程 API 校验 Token；`SecurityFrameworkService` 提供基于注解或代码的权限/角色校验逻辑。
- **上下文管理**：采用 `TransmittableThreadLocalSecurityContextHolderStrategy` 替换默认策略，确保在异步线程池中安全传递用户身份信息。
- **日志扩展**：通过 `YudaoOperateLogConfiguration` 集成 `bizlog-sdk`，提供 `ILogRecordService` 实现以支持业务操作日志的持久化。
