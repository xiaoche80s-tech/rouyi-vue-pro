- **模块化封装规范**：所有子模块遵循 `yudao-spring-boot-starter-*` 命名约定，内部严格划分为 `config`（自动配置类）与 `core`（核心逻辑）包结构，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 实现 SPI 自动装配。
- **基础依赖契约**：`yudao-common` 作为唯一的基础依赖模块，定义了全局统一的异常体系（`ServiceException`）、响应对象（`CommonResult`）及跨模块 API 接口，确保各 Starter 在错误处理与数据交互上的一致性。
- **业务与框架分离**：明确区分“框架组件”（如 MyBatis、Redis 增强）与“业务组件”（如租户、数据权限，命名含 `biz`），前者提供技术底层支持，后者注入特定业务逻辑拦截器，共同构成可插拔的运行时环境。
