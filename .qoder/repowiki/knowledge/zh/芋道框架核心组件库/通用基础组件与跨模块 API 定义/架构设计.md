- 分层结构：`pojo`（`CommonResult`、分页参数）、`exception`（`ErrorCode`、`ServiceException`）、`enums`、`util`（JSON/集合/日期等）、`validation`（自定义注解）构成基础层；`biz` 包定义 `PermissionCommonApi`、`OAuth2TokenCommonApi` 等跨模块接口。
- 依赖方向：基础层零业务依赖，仅依赖 Spring/Jackson/Hutool 等底层库（`pom.xml` 中多为 `provided`）；`biz` 接口仅依赖 DTO，不依赖具体实现，确保被各 API 模块安全引用。
- 关键设计：`CommonResult` 统一返回结构并与 `ServiceException` 互通；`ErrorCode` 采用对象化设计支持国际化；`JsonUtils` 封装 Jackson 并定制 LocalDateTime 序列化。
