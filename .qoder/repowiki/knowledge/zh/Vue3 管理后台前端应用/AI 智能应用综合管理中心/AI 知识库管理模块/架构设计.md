- **层级联动机制**：采用 `knowledgeId` -> `documentId` 的路由参数链式传递模式。`knowledge/index.vue` 跳转至文档页时携带 `knowledgeId`，`document/index.vue` 跳转至分段页时携带 `documentId`，子页面在 `onMounted` 中校验参数存在性并自动加载对应层级的数据列表。
- **API 模块化封装**：在 `api/ai/knowledge/` 下按实体（knowledge, document, segment）拆分为独立的 API 模块，每个模块导出对应的 VO 接口定义与 CRUD 方法，保持前端数据层与后端 RESTful 接口的一一映射。
- **统一交互规范**：所有列表页均集成 `ContentWrap`、搜索表单、`el-table` 及 `Pagination` 组件；状态切换统一使用 `el-switch` 配合二次确认弹窗；删除操作均遵循“确认->调用 API->刷新列表”的标准流程。
