- **启动编排**：在 `main.ts` 中统一初始化 Pinia 状态管理、Vue Router、Element Plus 及全局自定义组件，并通过 `permission.ts` 注入全局路由守卫。
- **权限控制链路**：采用“后端驱动”模式，登录时获取用户菜单与权限标识，存储于 Pinia；路由守卫根据权限动态注册路由，视图层通过 `v-hasPermi` 和 `v-hasRole` 指令实现细粒度按钮/角色控制。
- **网络通信契约**：通过 Axios 拦截器统一处理 Token 注入、租户 ID 传递、无感知刷新令牌（Refresh Token）及 API 响应加解密，确保各业务模块接口调用的安全性与一致性。
- **模块化集成**：各业务子模块（如 OpsHub、BPM、AI 等）遵循统一的 `api/store/views` 分层结构，通过共享的基础设施（布局、Hooks、工具类）实现低耦合集成。
