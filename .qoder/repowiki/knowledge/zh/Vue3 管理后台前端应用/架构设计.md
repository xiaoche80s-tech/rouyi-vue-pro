- **启动编排**：在 `main.ts` 中按序初始化国际化、Pinia 状态管理、全局组件库及 Element Plus，最后挂载应用并触发权限校验。
- **权限路由体系**：通过 `permission.ts` 实现全局路由守卫，拦截未授权访问；登录后由后端返回菜单数据，动态调用 `router.addRoute` 注入业务路由。
- **网络通信层**：基于 Axios 封装统一请求实例，在 `service.ts` 中实现 Token 自动携带、无感知刷新（Refresh Token）、租户 ID 注入及 API 响应加解密。
- **状态持久化**：使用 Pinia 配合 `pinia-plugin-persistedstate` 插件，实现用户信息、字典数据及标签页状态的本地持久化存储。
