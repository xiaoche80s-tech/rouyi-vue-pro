- API 接口统一封装在 `src/api/system/user/index.ts` 中，按功能分组导出（如 `getUserPage`, `createUser`），并定义对应的 TypeScript 接口。
- 表单弹窗组件（如 `UserForm.vue`）均暴露 `open` 方法用于初始化，并通过 `defineEmits(['success'])` 通知父组件刷新数据。
- 权限控制通过 `v-hasPermi` 指令绑定到按钮元素，实现细粒度的操作权限拦截（如 `system:user:create`）。
- 用户选择器组件支持 `v-model` 双向绑定，并通过 `change` 事件抛出完整的用户对象或 ID 数组，以适应不同场景的数据需求。
