- 采用 API 层与视图层分离架构：`api/opshub/excelImport/index.ts` 封装模板下载、批量打包下载及文件上传接口；`views/opshub/excelImport/` 负责 UI 呈现与交互逻辑。
- 视图层采用组合式组件设计：`index.vue` 作为主入口，按 L0-L4 依赖层级组织业务卡片；`ImportCard.vue` 封装单个业务表的下载、上传及结果展示逻辑，实现高复用性。
- 类型定义集中管理：`types.ts` 统一定义卡片配置项（`ImportCardItem`）、枚举字段结构及导入结果模型，确保前后端数据契约的一致性。
- 交互设计遵循依赖导向：界面通过视觉分组（L0 基础主数据至 L4 补充数据）引导用户按正确顺序导入，避免外键约束或数据关联错误。
