- **分层架构**：采用 API 层（`api/bpm/model`, `api/bpm/definition`）与视图层（`views/bpm/model`）分离设计。
- **向导式交互**：`form/index.vue` 作为核心入口，通过四步向导（基本信息、表单设计、流程设计、更多设置）组织复杂建模逻辑。
- **多态设计器**：`ProcessDesign.vue` 根据模型类型动态切换 `BpmModelEditor`（基于 bpmn-js 封装）或 `SimpleModelDesign`。
- **状态协同**：利用 Vue `provide/inject` 机制在向导步骤间共享 `modelData` 与 `processData`，确保跨组件数据一致性。
- **预览集成**：`FormDesign.vue` 集成 `form-create` 引擎，实现流程表单的实时可视化预览。
