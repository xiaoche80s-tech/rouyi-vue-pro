- **分层架构**：采用标准的 API 层与视图层分离模式。`src/api/bpm/task/index.ts` 集中定义所有任务相关的 RESTful 接口（如分页查询、审批动作），视图层通过导入 API 模块进行数据交互。
- **模块化视图**：在 `src/views/bpm/task/` 下按业务场景划分子目录（`todo`, `done`, `manager`, `copy`），每个子目录包含独立的 `index.vue` 入口，实现不同任务维度的隔离与管理。
- **统一交互范式**：各视图组件均遵循“搜索栏 + 数据表格 + 分页”的布局结构，并通过路由跳转至统一的流程实例详情页（`BpmProcessInstanceDetail`）处理复杂的审批逻辑。
