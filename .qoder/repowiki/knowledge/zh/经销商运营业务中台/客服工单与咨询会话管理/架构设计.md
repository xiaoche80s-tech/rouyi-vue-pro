- **分层架构**：遵循 Controller-Service-Mapper 标准分层，通过 `CsTaskController` 和 `CsSessionController` 暴露 RESTful 接口。
- **BPM 深度集成**：工单状态机由 Flowable 引擎驱动，Service 层通过 `BpmProcessInstanceApi` 发起流程，并利用 `getTodoProcessInstanceIds` 等 API 实现基于工作流任务的待办/已办查询。
- **事件驱动解耦**：定义 `CsTaskStatusChangeEvent` 并在 BPM 回调或业务操作后发布，供其他模块监听以执行跨域逻辑。
- **实时通信**：封装 `CsWebSocketService` 提供事务感知的异步消息推送，支持工单通知、聊天消息及会话事件的精准分发。
- **数据访问**：使用 MyBatis-Plus，在 Mapper 层通过 `LambdaQueryWrapperX` 实现动态条件组装，并针对 BPM 流程实例 ID 进行反查优化。
