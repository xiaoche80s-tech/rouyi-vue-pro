- **分层架构**：遵循 Controller-Service-Mapper 标准三层结构，Controller 层处理 HTTP 请求与 VO/DO 转换，Service 层封装业务逻辑（如唯一性校验、关联关系维护），Mapper 层基于 MyBatis Plus 实现数据持久化。
- **核心领域模型**：包含 `DealerInfo`（经销商）、`DealerProductLine`（产品线）及 `DealerUserScope`（用户授权范围）等实体，通过 `DealerProductLineRelation` 维护多对多绑定关系。
- **接口边界**：提供 RESTful API 供前端调用，涵盖基础 CRUD、分页查询、精简列表获取以及复杂的授权分配（如 `assign` 用户经销商权限）。
- **依赖方向**：Service 层依赖 Mapper 进行数据操作，并跨模块调用 `AdminUserApi` 获取用户信息以组装复杂的视图对象（VO）。
