- 模块按通道划分为 sms、notify、mail 三个子域，各自在 api 层提供 REST 封装，在 views 层提供列表页、表单弹窗与详情组件。
- 采用“列表页 + Dialog 表单”的交互边界：index.vue 负责查询/分页/批量操作，Form 组件通过 defineExpose({ open }) 被父页面调用，提交后 emit('success') 触发列表刷新。
- 模板类功能依赖对应的基础配置精简列表（如短信渠道、邮件账号），在 Form 打开时异步加载并用于下拉选择，形成“模板 → 渠道/账号”的内部依赖方向。
- 权限控制通过 v-hasPermi 指令在按钮粒度生效；字典展示统一使用 dict-tag 与 DICT_TYPE 常量，保证枚举渲染一致性。
