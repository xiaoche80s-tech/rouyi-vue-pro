- API 层 (`api/opshub/productLine/index.ts`) 定义产品线 CRUD、精简列表获取以及经销商绑定/解绑/查询接口，采用 RESTful 风格。
- 视图层 (`views/opshub/productLine/`) 采用主从结构：`index.vue` 负责产品线列表展示与搜索，通过权限指令控制操作按钮；`ProductLineForm.vue` 封装新增/修改表单逻辑；`ProductLineDealerBindForm.vue` 使用 `el-drawer` 实现经销商绑定管理，内部通过计算属性动态过滤已绑定经销商以提供可选列表。
- 数据流遵循“列表页触发 -> 调用 API -> 弹窗/抽屉交互 -> 成功后刷新列表”的模式，组件间通过 `ref` 和 `emit` 进行通信。
