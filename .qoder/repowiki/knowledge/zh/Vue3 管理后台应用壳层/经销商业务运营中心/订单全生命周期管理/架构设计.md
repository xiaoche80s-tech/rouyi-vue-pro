- **分层架构**：采用 API 层（`api/opshub/order/index.ts`）与视图层（`views/opshub/order/`）分离的设计，API 层封装 RESTful 请求并定义 TypeScript 接口。
- **组件化设计**：视图层由主入口 `index.vue` 统筹，拆分为统计卡片（`OrderStatisticsCards`）、筛选栏（`OrderFilterBar`）、数据表格（`OrderTable`）及多个业务弹窗（如 `ApplyPaymentModal`）。
- **详情模块化**：订单详情通过 `OrderDetailModal` 承载，内部利用 Tab 页签进一步拆解为基本信息、付款、开票、退货、物流及沟通记录等子模块（`tabs/` 目录），实现复杂信息的结构化展示。
- **交互逻辑**：主页面负责状态管理与批量操作分发，子组件通过 `emit` 事件与父组件通信，保持单向数据流。
