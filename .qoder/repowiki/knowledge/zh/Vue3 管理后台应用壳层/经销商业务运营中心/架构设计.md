- **统一咨询集成模式**：各业务模块（签约、订单、基础数据等）均通过 `useCsConsult` Hook 封装的标准化接口发起咨询，自动创建携带业务上下文（如合同号、经销商编码）的会话并唤起全局 `ChatWindow` 组件。
- **共享基础数据依赖**：多个业务页面在初始化时并行调用 `DealerApi.getSimpleDealerList` 和 `ProductLineApi.getSimpleProductLineList`，为筛选栏和业务逻辑提供统一的维度数据支撑。
- **模块化视图编排**：采用“统计卡片 + 筛选栏 + 操作表格 + 趋势图”的标准化布局范式，并通过独立的 API 模块（`api/opshub/`）实现前后端接口的物理隔离与按需加载。
