- API 层：`src/api/infra/dataSourceConfig/index.ts` 定义 `DataSourceConfigVO` 及 CRUD 接口，统一通过 `@/config/axios` 发起请求。
- 视图层：`index.vue` 负责列表展示、搜索栏操作（新增、批量删除）及行内编辑/删除，集成权限指令 `v-hasPermi`。
- 表单层：`DataSourceConfigForm.vue` 封装新增/修改弹窗逻辑，通过 `defineExpose` 暴露 `open` 方法，提交后触发 `success` 事件通知父组件刷新。
- 交互约束：前端硬编码保护 `id === 0` 的主数据源，禁止在列表操作中对其进行编辑或删除。
