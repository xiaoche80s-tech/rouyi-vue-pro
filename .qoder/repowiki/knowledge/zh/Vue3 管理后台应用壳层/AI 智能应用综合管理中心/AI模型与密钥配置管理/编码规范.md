- API 层统一导出常量对象（如 `ModelApi`）封装请求方法，并定义对应的 TypeScript 接口（如 `ModelVO`）以规范数据结构。
- 视图层采用“列表页 + 表单弹窗”的组合模式，列表页负责搜索、展示与分页，表单弹窗通过 `Dialog` 组件实现新增与修改功能的复用。
- 使用 `v-hasPermi` 指令对新增、编辑、删除等操作按钮进行细粒度的权限控制，确保界面元素与用户权限匹配。
- 表单提交前执行统一的字段校验（`formRef.value.validate()`），并根据业务类型（如 `AiModelTypeEnum.CHAT`）动态显示或过滤特定参数（如 temperature, maxTokens）。
