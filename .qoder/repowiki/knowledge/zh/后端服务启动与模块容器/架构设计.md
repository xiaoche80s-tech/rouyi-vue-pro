- 采用 Spring Boot 单体架构，`YudaoServerApplication` 为唯一启动类，通过 `scanBasePackages` 动态扫描基础包下的 server 与 module 目录。
- 扮演“空壳容器”角色，在 `pom.xml` 中显式引入 system、infra、bpm、im、opshub 等核心业务模块依赖，实现功能组装。
- 内置 `DefaultController` 提供兜底路由机制，针对未启用的可选模块（如 mall、erp、crm 等）返回友好的禁用提示而非 404。
- 配置层通过 `application.yaml` 统一管理多环境参数，涵盖数据库、Redis、消息队列及 AI 大模型等复杂集成场景。
