- **权限切面层**：通过 `CrmPermission` 注解与 `CrmPermissionAspect` AOP 切面，实现基于 SpEL 表达式的细粒度数据权限校验（支持负责人、团队成员及下级权限继承）。
- **日志解析层**：在 `operatelog/core` 下实现多个 `IParseFunction`（如客户、联系人、管理员名称解析），将操作日志中的 ID 转换为可读的业务名称。
- **Excel 增强层**：通过 `AreaExcelColumnSelectFunction` 实现 Excel 导入时的地区下拉选项动态获取。
- **Web 配置层**：`CrmWebConfiguration` 负责注册 Swagger API 分组，隔离 CRM 模块接口文档。
