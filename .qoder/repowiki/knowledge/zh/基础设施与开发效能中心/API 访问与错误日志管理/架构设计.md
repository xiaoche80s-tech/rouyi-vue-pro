- 分层架构：`api/logger` 提供 `ApiAccessLogApiImpl`/`ApiErrorLogApiImpl` 实现框架层 `ApiAccessLogCommonApi`/`ApiErrorLogCommonApi` 接口，供其他模块异步写入日志；`controller/admin/logger` 提供管理后台 REST 接口（分页查询、详情、Excel 导出）；`service/logger` 封装业务逻辑；`dal/dataobject/logger` 与 `dal/mysql/logger` 负责数据持久化。
- 数据模型：`ApiAccessLogDO`/`ApiErrorLogDO` 继承 `BaseDO`，通过 MyBatis-Plus 映射到 `infra_api_access_log`/`infra_api_error_log` 表。
- 运维能力：`job/logger` 下的 `AccessLogCleanJob`/`ErrorLogCleanJob` 基于 Quartz 定时清理过期日志（默认保留 14 天，分批删除），并使用 `@TenantIgnore` 忽略多租户隔离。
- 依赖方向：Controller/API Impl → Service → Mapper/DO；枚举 `ApiErrorLogProcessStatusEnum` 支撑错误日志处理状态流转。
