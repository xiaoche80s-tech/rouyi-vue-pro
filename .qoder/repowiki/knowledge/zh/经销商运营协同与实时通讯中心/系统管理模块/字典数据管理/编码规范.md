- API 模块按实体拆分文件（`dict.type.ts`、`dict.data.ts`），导出 VO 接口与 CRUD 函数，命名遵循 `get/create/update/delete/export` 前缀规范。
- 列表页采用“搜索栏 + 表格 + 分页”布局，搜索条件重置时调用 `resetFields()` 并重新查询，分页变更触发 `getList()` 刷新。
- 新增/编辑统一使用弹窗表单组件，通过 `ref` 获取实例并调用 `open(type, id?, extra?)` 方法打开，操作成功后 emit `success` 事件通知父组件刷新列表。
- 删除与批量删除均先执行二次确认（`message.delConfirm()`），成功后提示并刷新列表；按钮状态受选中项数量控制（`:disabled="checkedIds.length === 0"`）。
- 状态字段使用字典工具 `getIntDictOptions(DICT_TYPE.COMMON_STATUS)` 渲染选项与标签，保持前后端状态枚举一致。
- 导出功能通过 `request.download` 获取二进制流，再调用 `download.excel(data, filename)` 触发浏览器下载，并在请求期间显示 loading 状态。
