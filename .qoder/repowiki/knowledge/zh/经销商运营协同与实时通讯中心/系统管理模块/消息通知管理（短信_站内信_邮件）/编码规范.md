- 列表页统一使用 ContentWrap 包裹搜索表单与表格，配合 el-table + Pagination 完成分页展示与 loading 状态管理。
- 表单弹窗统一基于 Dialog 组件，通过 defineExpose({ open }) 暴露打开方法，并在 submitForm 中校验后调用 API，成功后 emit('success')。
- API 层按资源拆分目录（channel/log/template 等），每个 index.ts 导出 VO 接口与 CRUD 方法，视图层以命名空间方式导入（如 * as XxxApi）。
- 删除操作均执行二次确认（message.delConfirm），单条与批量删除后统一刷新列表并清空选中状态。
- 字典相关字段在表格中使用 dict-tag 渲染，选项来源统一通过 getIntDictOptions(DICT_TYPE.*) 获取。
