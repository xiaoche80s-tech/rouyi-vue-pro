- **API 层**：按业务域垂直拆分至 `src/api/im/` 下的子目录（`friend`, `group`, `message`, `channel`, `rtc`, `face`），每个子模块通过 `index.ts` 导出类型定义（VO/ReqVO）与请求方法，统一依赖 `@/config/axios` 进行 HTTP 通信。
- **工具层**：集中于 `src/views/im/utils/`，包含协议常量定义（`constants.ts`）、运行配置与阈值（`config.ts`）、消息内容编解码与展示逻辑（`message.ts`）、会话摘要计算（`conversation.ts`）以及基于 IndexedDB 的本地持久化方案（`db.ts`）。
- **依赖方向**：API 层保持无状态，仅负责数据传输；工具层为视图层（Store/Component）提供纯函数支持，其中 `db.ts` 实现了多 Store 共享的底层数据访问接口，确保离线数据的一致性。
