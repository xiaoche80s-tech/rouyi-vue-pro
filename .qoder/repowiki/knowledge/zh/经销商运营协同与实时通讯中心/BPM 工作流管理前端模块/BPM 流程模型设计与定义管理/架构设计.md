- **分层架构**：采用 API 层（`api/bpm/model`, `api/bpm/definition`）与视图层（`views/bpm/model`）分离的设计，API 封装 RESTful 请求，视图层负责交互逻辑。
- **向导式建模**：`form/index.vue` 实现四步向导（基本信息、表单设计、流程设计、更多设置），通过 `provide/inject` 在父子组件间共享 `modelData` 和 `processData` 状态。
- **双引擎适配**：`ProcessDesign.vue` 根据 `BpmModelType` 动态切换 BPMN 编辑器（`editor/index.vue`）或简易流程设计器（`SimpleModelDesign`）。
- **分类聚合展示**：主列表 `index.vue` 使用 `vuedraggable` 实现按业务分类的拖拽排序，并通过前端聚合逻辑将模型映射到对应分类下。
- **定义恢复机制**：`definition/index.vue` 支持从已部署的流程定义中“恢复”模型，通过路由参数 `type: 'definition'` 触发数据逆向转换逻辑。
