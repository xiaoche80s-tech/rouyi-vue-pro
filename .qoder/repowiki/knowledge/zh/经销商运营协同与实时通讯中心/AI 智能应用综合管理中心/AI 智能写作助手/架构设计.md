- **分层架构**：采用标准的 API 层（`api/ai/write/index.ts`）与视图层（`views/ai/write/`）分离设计。
- **视图组织**：主界面（`index/index.vue`）采用左右分栏布局，左侧（`Left.vue`）负责参数配置与表单提交，右侧（`Right.vue`）负责流式内容展示与交互；管理界面（`manager/index.vue`）提供历史记录的查询与删除。
- **通信机制**：通过 `@microsoft/fetch-event-source` 实现 SSE 流式通信，利用 `AbortController` 控制生成中断。
- **状态管理**：组件间通过 Props/Emits 及 `v-model` 进行状态同步，父组件协调流式数据的接收与 UI 更新。
