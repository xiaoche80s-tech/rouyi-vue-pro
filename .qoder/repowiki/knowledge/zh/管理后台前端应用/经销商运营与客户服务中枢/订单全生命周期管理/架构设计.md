- **分层架构**：采用标准的 API 层（`api/opshub/order/index.ts`）与视图层（`views/opshub/order/`）分离模式，API 层封装 RESTful 请求并定义 TypeScript 接口。
- **组件化设计**：视图层采用“主页面 + 弹窗 + 标签页”的组合模式。`index.vue` 负责整体布局与状态管理；`OrderDetailModal.vue` 通过 `el-tabs` 集成 `BasicInfoTab`、`PaymentInfoTab` 等 6 个子标签页，实现详情信息的模块化展示。
- **交互逻辑**：通过 `OrderStatisticsCards` 实现统计数据的可视化与快速筛选联动；`OrderTable` 结合权限指令（`v-hasPermi`）动态渲染操作项，支持批量业务处理（付款、开票、退货）。
- **依赖关系**：视图组件依赖 `@/config/axios` 进行网络请求，依赖 `@/utils/formatTime` 和 `@/utils/permission` 进行数据格式化与权限校验。
