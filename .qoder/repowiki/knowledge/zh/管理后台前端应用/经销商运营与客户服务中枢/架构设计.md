- **统一 API 边界**：所有子模块共享 `/api/opshub/` 路径前缀，通过 `request` 实例统一处理认证与拦截。
- **跨模块业务联动**：售后服务（aftersale）与客户服务（customerservice）通过“批量咨询”接口联动；操作请求（csOpReq）支持从签约、订单等模块直接发起，实现业务闭环。
- **通用附件支撑**：独立的 `csAttachment` 模块为工单、操作请求等业务实体提供统一的文件上传与关联管理能力。
- **标准化视图架构**：各子模块遵循“筛选栏 + 统计卡片 + 数据表格 + 详情弹窗”的 UI 模式，并通过 Tab 页签（如 customerservice）或独立页面（如 order, signing）进行功能分区。
