- **模块化路由与视图隔离**：采用 `src/views` 按业务域（如 `opshub`, `system`, `bpm`）划分模块，配合 `src/router` 实现动态路由加载与权限控制。
- **分层 API 契约设计**：在 `src/api` 下建立与后端微服务对应的目录结构，通过统一的 Axios 实例封装请求拦截、错误处理及 Token 刷新逻辑。
- **全局状态与组件共享**：利用 Pinia 管理用户信息、字典数据及标签页状态；通过 `src/components` 提供高度复用的业务组件（如工作流设计器、报表编辑器）。
- **多环境配置体系**：基于 Vite 的环境变量机制（`.env.*`），实现开发、测试、生产等不同部署环境的配置隔离与自动化切换。
