- API层：`api/system/area/index.ts` 和 `api/system/notice/index.ts` 封装后端 REST 接口，使用统一的 `request` 客户端。
- 视图层：`views/system/area/index.vue` 使用 `el-table-v2` 虚拟化表格展示地区树，`AreaForm.vue` 提供 IP 查询弹窗；`views/system/notice/index.vue` 实现公告列表的分页、搜索、批量删除及推送操作，`NoticeForm.vue` 处理公告的新增与编辑表单。
- 交互模式：采用“列表页 + 弹窗表单”的经典 CRUD 架构，通过 `ref` 暴露子组件 `open` 方法控制弹窗显隐，利用 `emit('success')` 触发父组件列表刷新。
