- **分层架构**：采用标准的 API 层与视图层分离模式。`src/api/system/user/` 定义数据接口与类型（如 `UserVO`），`src/views/system/user/` 负责页面交互与业务逻辑。
- **核心入口**：`index.vue` 作为主管理页面，集成左侧部门树（`DeptTreeSelect`）与右侧用户列表，支持分页、搜索及批量操作。
- **功能模块化**：通过子组件拆分复杂功能，包括 `UserForm.vue`（新增/编辑）、`UserImportForm.vue`（Excel 导入）、`UserAssignRoleForm.vue`（角色分配）。
- **通用选择器**：在 `components/` 目录下提供 `UserSelect.vue`（下拉式）和 `UserSelectV2.vue`（弹窗式）等复用组件，支持单选/多选及部门过滤，服务于跨模块的用户选择需求。
