# 工单详情页由弹窗重构为独立路由页面

_来源：32a9ec7 → 7451d2e 提交周期内记录的编码计划——内容为规划时意图，实现可能滞后或有出入。_

**状态：** accepted

## 背景
原有的 Dialog 弹窗形式无法承载完整的 BPM 审批时间线、执行人员操作区（附件/留言）及复杂的交互状态，且弹窗内嵌导致路由状态管理困难，不利于后续功能扩展。

## 决策驱动
- 信息展示密度
- 交互体验
- 路由状态管理

## 备选方案
- **重构为独立路由页面 (/opshub/task-detail)** — 优点：拥有完整屏幕空间，支持浏览器前进/后退，易于管理复杂状态和嵌套组件；缺点：需修改列表页跳转逻辑，增加路由配置
- **保留 Dialog 并增强内部布局** _（已否决）_ — 优点：开发改动较小，用户上下文不切换；缺点：空间受限，难以展示长时间线和多区域操作，状态管理复杂

## 决策
将工单详情从 Dialog 组件重构为独立页面，新增 /opshub/task-detail 路由。页面划分为工单信息、审批时间线、执行操作区（含附件与留言）三大板块，并新建 ops_cs_task_comment 表支持独立于 BPM 的工单留言功能。

## 影响
提升了详情页的信息承载能力和用户体验。新增了留言模块的后端 CRUD 及前端 API。列表页需由弹窗触发改为路由跳转。
