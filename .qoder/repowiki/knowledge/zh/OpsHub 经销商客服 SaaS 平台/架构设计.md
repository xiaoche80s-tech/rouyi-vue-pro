- **单体模块化架构**：采用 Maven 多模块聚合模式，`yudao-server` 作为唯一启动容器，显式依赖 `system`、`infra`、`bpm`、`im` 及业务核心 `opshub` 模块。
- **分层隔离设计**：`yudao-framework` 提供统一的 Spring Boot Starter 技术底座（如数据权限、多租户、安全认证），业务模块仅关注领域逻辑并通过 API 接口进行内部通信。
- **前后端分离部署**：后端通过 RESTful API 提供服务，前端 `yudao-ui-admin-vue3` 作为独立应用壳层，通过动态路由加载各业务模块视图。
