- 列表页统一采用“查询条件表单 + el-table 分页展示 + Pagination 组件”的 CRUD 模板，并在 onMounted 中触发首次 getList。
- API 调用集中在 `api/im/manager/<domain>/index.ts`，以具名导出函数封装请求，并定义对应的 VO/Param 接口供视图层使用。
- 状态与枚举展示统一通过字典工具（DICT_TYPE + getIntDictOptions/getBoolDictOptions）配合 dict-tag 渲染，避免硬编码文案。
- 操作按钮普遍使用 v-hasPermi 进行权限控制，删除/批量删除等危险操作先执行二次确认再调用后端接口。
- 详情页/表单页通过 ref 暴露 open 方法，由列表页调用打开弹窗或抽屉，成功后通过 emit 通知列表刷新。
