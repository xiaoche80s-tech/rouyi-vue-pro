- **统一咨询集成**：通过 `useCsConsult` Hook 封装会话创建逻辑，在订单、签约等业务模块中提供一致的“批量/单条咨询”入口，并自动携带业务上下文（如合同号、产品线）。
- **实时通信架构**：基于 `useCsWebSocket` 建立全局监听，将后端 BPM 状态变更（如工单转派）及会话事件（如新消息）直接映射到前端 UI 更新，消除冗余 HTTP 轮询。
- **BPM 驱动的任务流**：工单模块深度集成 Flowable 引擎，前端通过 `getBpmTaskId` 等接口实现转单、审批等操作，确保业务状态与流程实例同步。
- **精细化数据授权**：各业务列表（订单、签约、工单）均叠加经销商与产品线维度的数据权限过滤，确保执行员仅能访问授权范围内的业务数据。
