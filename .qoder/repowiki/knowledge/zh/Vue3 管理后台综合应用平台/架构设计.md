- **动态路由与权限控制**：采用后端驱动的路由模式，在 `permission.ts` 守卫中根据用户角色动态生成并挂载路由表，结合 `v-hasPermi` 指令实现细粒度功能权限控制。
- **统一通信与状态协同**：通过封装 Axios 实例实现无感知 Token 刷新与多租户隔离；利用 Pinia 集中管理用户、字典及全局配置状态，确保跨模块数据一致性。
- **标准化 CRUD 交互范式**：提供 `useTable`、`useForm` 及 `useCrudSchemas` 等组合式 API，将查询、列表、表单及详情页面的逻辑与 UI 配置解耦，实现业务功能的快速组装。
- **实时消息与 WebSocket 集成**：内置 `useCsWebSocket` Hook 处理长连接心跳与消息分发，支持会话事件、工单通知及系统广播的实时推送与 UI 响应。
