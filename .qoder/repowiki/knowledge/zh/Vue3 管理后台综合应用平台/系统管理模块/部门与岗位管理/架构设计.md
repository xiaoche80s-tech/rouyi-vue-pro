- 采用 API 层与视图层分离架构，API 层（`api/system/dept|post/index.ts`）封装 RESTful 请求，视图层（`views/system/dept|post/`）负责 UI 渲染与交互逻辑。
- 视图层遵循“列表页 + 表单弹窗组件”模式，列表页（`index.vue`）处理搜索、分页、批量删除等逻辑，表单页（`DeptForm.vue`/`PostForm.vue`）通过 `defineExpose` 暴露 `open` 方法供父组件调用。
- 部门模块引入树形数据处理工具（`handleTree`）及树形选择组件（`DeptTreeSelect.vue`），以支持层级化展示；岗位模块则侧重于分页列表与 Excel 导出功能。
- 权限控制通过自定义指令 `v-hasPermi` 在按钮级别实现，确保操作安全性。
