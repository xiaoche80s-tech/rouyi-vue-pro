- **配置层**：通过 `ImProperties` 统一管理好友、群聊、消息、表情及 RTC 等子模块的运行时参数，支持细粒度功能开关（如已读回执、自动通过好友）。
- **RTC 集成层**：在 `framework.rtc` 包下封装 LiveKit 客户端，包含 `LiveKitClient` 核心类负责 JWT Token 签发（进房/管理）、Server API 调用（删除房间、查询参与者）及 Webhook 签名校验，并通过 `ImRtcConfiguration` 注入 Spring 容器。
- **Web 适配层**：`ImWebConfiguration` 负责注册 Swagger/OpenAPI 分组，确保 IM 接口在文档中独立展示。
- **常量与契约层**：在 `enums` 包下定义全局错误码 `ErrorCodeConstants`（覆盖消息、群、好友、RTC 等场景）、会话类型枚举 `ImConversationTypeEnum` 及通用常量 `ImCommonConstants`，确立前后端交互与内部业务逻辑的基础契约。
