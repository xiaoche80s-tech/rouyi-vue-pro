- API 模块采用统一的导出模式：在 `index.ts` 中同时定义 TypeScript 接口（如 `RespVO`, `ReqVO`）和对应的请求函数，请求函数内部调用统一的 `request` 实例并指定 URL 路径。
- 消息类型与状态使用常量对象（`as const`）配合工具函数（如 `isNormalMessage`, `isGroupNotification`）进行二分或段位识别，避免在业务代码中硬编码数字枚举。
- 本地数据库（IndexedDB）操作封装为单例 `DbClient`，通过 `clientConversationId`（格式为 `type:targetId`）和 `messageKey` 建立稳定的主键索引，并利用 `session` 机制防止跨用户或刷新后的脏数据写入。
- 消息内容（content）统一采用 JSON 字符串序列化存储，解析时通过泛型工具函数 `parseMessage<T>` 处理，并在涉及媒体资源（blob URL）时提供专门的内存释放工具 `revokeBlobUrlsInContent`。
