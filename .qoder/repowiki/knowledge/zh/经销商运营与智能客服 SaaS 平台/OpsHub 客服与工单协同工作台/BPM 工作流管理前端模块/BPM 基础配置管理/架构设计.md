- 采用 API 层与视图层分离架构，API 层（`src/api/bpm/*`）封装 RESTful 请求，视图层（`src/views/bpm/*`）负责交互逻辑。
- 表单管理模块集成 `@form-create/designer` 实现低代码表单设计，通过 `editor/index.vue` 进行可视化编排，并通过 `utils/formCreate` 处理配置序列化。
- 流程分类与用户组模块采用标准的“列表页 + 弹窗表单”模式，通过子组件（`CategoryForm.vue`, `UserGroupForm.vue`）实现 CRUD 操作，并利用 `defineExpose` 暴露 `open` 方法供父组件调用。
- 权限控制通过 `v-hasPermi` 指令在按钮级别进行细粒度管控，确保操作安全性。
