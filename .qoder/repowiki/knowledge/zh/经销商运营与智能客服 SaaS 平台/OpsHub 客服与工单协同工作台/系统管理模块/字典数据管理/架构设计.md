- API 层：`dict.type.ts` 与 `dict.data.ts` 封装 REST 接口，统一通过 `request` 客户端调用后端 `/system/dict-type` 与 `/system/dict-data` 资源。
- 视图层：`views/system/dict/index.vue` 负责字典类型列表与操作；`views/system/dict/data/index.vue` 负责指定类型下的字典数据列表。
- 表单组件：`DictTypeForm.vue` 与 `DictDataForm.vue` 以弹窗形式承载新增/编辑，通过 `defineExpose({ open })` 暴露方法，由父页面调用。
- 交互边界：类型页通过路由跳转至数据页（`/dict/type/data/:type`），数据页从路由参数获取 `dictType` 并联动筛选。
- 通用能力：分页、搜索、批量删除、导出均在各自主页面实现，依赖 `Pagination`、`ContentWrap`、`Dialog` 等基础组件。
