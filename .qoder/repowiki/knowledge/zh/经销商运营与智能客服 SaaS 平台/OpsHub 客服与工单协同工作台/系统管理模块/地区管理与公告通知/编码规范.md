- API 模块导出函数采用 PascalCase 命名（如 `getAreaTree`, `createNotice`），并统一返回 Promise。
- 视图组件使用 `defineOptions({ name: '...' })` 显式声明组件名称，便于调试和缓存识别。
- 表单弹窗组件通过 `defineExpose({ open })` 暴露打开方法，父组件通过 `ref` 调用而非 props 控制显隐。
- 列表页操作按钮集成 `v-hasPermi` 指令进行权限控制，确保前端操作的安全性。
- 使用 `useMessage()` 组合式函数统一处理成功提示、删除确认等用户交互反馈。
