- API 接口按业务实体（conversation, message）分包组织，并统一导出 TypeScript 接口定义（VO）与异步方法集合。
- 视图组件采用“容器-展示”模式，复杂页面由一个主 `.vue` 文件协调多个位于 `components/` 下的子组件，通过 Props 传递数据，Emits 触发行为。
- 流式响应处理遵循“占位符预加载 + 增量更新”模式，先在本地列表插入临时消息对象，再通过 SSE 回调实时更新内容与推理状态。
- UI 枚举与常量集中定义在 `utils/constants.ts` 中，并按功能前缀（如 `AiPlatformEnum`）分类，避免硬编码散落在业务逻辑中。
