- **实时通信架构**：基于 `useCsWebSocket` Hook 统一封装 WebSocket 连接，通过 `cs-chat-message`、`cs-session-event` 等消息类型驱动前端状态更新，实现多端数据同步。
- **跨模块组件复用**：`opshub` 模块直接复用 `im_chat` 模块的 `ChatHeader`、`ChatMessageList` 等通用聊天组件，并通过 `mode` 属性适配不同业务场景（如经销商视图与客服视图）。
- **BPM 流程集成**：在 `CsTask` API 层集成 BPM 任务查询与转单接口，结合节点级事件监听器（后端），在前端实现工单状态与流程进度的实时联动。
- **状态管理协同**：利用 Pinia Store 与本地 Ref 状态结合，通过 `session-updated` 事件总线机制，确保列表页与详情页在复杂交互下的数据一致性。
