- 入口与配置：通过 `YudaoTenantAutoConfiguration`（Spring Boot AutoConfiguration）按层注册 Bean，支持 `yudao.tenant.enable=false` 全局禁用；属性由 `TenantProperties` 承载。
- 上下文边界：`TenantContextHolder` 使用 `TransmittableThreadLocal` 维护当前租户ID与忽略标志，作为跨线程/异步场景的统一上下文载体。
- Web 层：`TenantContextWebFilter` 从请求头解析 tenant-id 并写入上下文；`TenantVisitContextInterceptor` 结合安全服务做访问期租户校验；`TenantSecurityWebFilter` 基于 `@TenantIgnore` 扫描构建忽略URL集合进行放行。
- DB 层：基于 MyBatis Plus 的 `TenantLineInnerInterceptor` + `TenantDatabaseInterceptor` 实现 SQL 级租户条件注入；忽略策略覆盖全局忽略、配置表、非项目表、继承 `TenantBaseDO` 与类级 `@TenantIgnore`。
- AOP 与任务：`TenantIgnoreAspect` 在方法/类标注 `@TenantIgnore` 时临时开启忽略；`TenantJobAspect` 对标注 `@TenantJob` 的任务按租户列表并行执行并通过 `TenantUtils.execute` 切换上下文。
- MQ 与缓存：为 Redis/RocketMQ/RabbitMQ/Kafka 提供初始化器与拦截器以透传租户信息；Redis 缓存侧提供 `TenantRedisCacheManager`（主 Bean）实现租户维度的缓存隔离与事务感知。
