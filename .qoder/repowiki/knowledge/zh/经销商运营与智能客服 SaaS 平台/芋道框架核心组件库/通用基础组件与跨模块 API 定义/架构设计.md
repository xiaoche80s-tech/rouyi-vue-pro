- **分层结构**：模块内部划分为 `biz`（跨模块 API 接口及 DTO）、`core`（核心接口）、`enums`（全局枚举）、`exception`（统一异常体系）、`pojo`（通用返回与分页对象）、`util`（各类工具类）和 `validation`（自定义校验注解）。
- **接口边界**：通过 `biz` 包下的 `*CommonApi` 接口（如 `PermissionCommonApi`、`OAuth2TokenCommonApi`）定义模块间通信契约，实现业务模块解耦。
- **依赖方向**：作为框架底层基础模块，不依赖其他业务模块；引入 Spring、Jackson、Hutool 等作为 `provided` 或基础依赖，确保轻量化与通用性。
- **关键入口**：`CommonResult` 作为统一响应载体，`ServiceException` 作为业务异常基类，`JsonUtils` 提供全局 JSON 处理能力。
