- 自动配置层：通过 `YudaoRedisAutoConfiguration` 和 `YudaoCacheAutoConfiguration` 定义 Bean，并在 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 中注册。
- 核心扩展：`TimeoutRedisCacheManager` 继承 `RedisCacheManager`，解析 `cacheNames` 中的 `#ttl` 格式以动态设置过期时间。
- 序列化策略：统一使用 Jackson JSON 序列化 Value，并注册 `JavaTimeModule` 解决 `LocalDateTime` 兼容性问题；Key 采用 String 序列化。
- 依赖管理：基于 `redisson-spring-boot-starter` 和 `spring-boot-starter-cache`，通过 `@AutoConfiguration(before = ...)` 确保自定义 `RedisTemplate` 优先加载。
