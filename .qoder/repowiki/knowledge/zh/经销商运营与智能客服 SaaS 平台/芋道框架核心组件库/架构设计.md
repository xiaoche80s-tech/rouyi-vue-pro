- **模块化 Starter 架构**：采用独立的 `yudao-spring-boot-starter-*` 模块封装不同技术领域（如 Web、Security、MyBatis、Redis 等），利用 Spring Boot 的 `AutoConfiguration` 机制实现自动装配。
- **统一契约定义**：`yudao-common` 模块作为底层依赖，定义了全局通用的异常体系、返回结果 (`CommonResult`)、分页对象及跨模块调用的 API 接口契约，确保各 Starter 间的基础数据类型一致。
- **业务与技术分离**：明确区分“框架组件”（如 MyBatis、Redis 增强）与“业务组件”（如多租户、数据权限、IP 解析），业务组件通过 `biz` 命名标识，在不侵入业务逻辑的前提下提供透明化增强。
- **上下文传递机制**：多个 Starter（如 Tenant、Security、DataPermission）协同工作，通过 ThreadLocal 或 TransmittableThreadLocal 在 Web 请求、异步任务及 MQ 消费间传递用户身份、租户 ID 等上下文信息。
