- 列表页与表单组件之间通过 `ref` 调用子组件暴露的 `open` 方法进行弹窗控制，并通过 `@success` 事件回调刷新列表数据。
- 所有增删改操作均使用 `try...finally` 块管理 `formLoading` 或 `loading` 状态，确保异步操作结束后 UI 状态正确恢复。
- API 接口定义统一使用 TypeScript 接口（如 `DeptVO`, `PostVO`）描述数据结构，并导出语义化的异步函数（如 `getDeptPage`, `createPost`）。
- 表单校验规则（`formRules`）在表单组件内部定义，并在提交前通过 `formRef.value.validate()` 进行显式校验。
