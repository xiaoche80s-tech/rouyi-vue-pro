- 采用“视图层 + API 层”两层结构：`views/im/manager/**/index.vue` 作为各子域入口页，`api/im/manager/**/index.ts` 封装 REST 接口与 TS 类型。
- 按业务域垂直拆分子目录：`channel`（频道）、`friend`（好友/申请）、`group`（群组/申请/封禁）、`message`（私聊/群聊详情与预览）、`rtc`（通话记录）、`sensitiveword`（敏感词）、`statistics`（统计看板），以及 `face`（表情包/用户表情）。
- 交互模式以“搜索表单 + 表格分页 + 详情/操作弹窗”为主；列表页通过 `defineOptions({ name: '...' })` 声明路由名称，并配合 `v-hasPermi` 做按钮级权限控制。
- 共享能力通过局部组件与工具模块复用：如 `UserSelectV2`、`MessageContentPreview`、各类 `*Form/*Detail/*Select` 组件，以及字典/时间格式化等 util。
