- **业务编码驱动架构**：全模块摒弃物理 ID 关联，统一采用 `dealerCode` 和 `productLineCode` 作为跨表、跨模块交互的唯一标识，确保数据在重命名或迁移场景下的稳定性。
- **集中式范围授权（Scope）**：设立独立的 `scope` 管理视图，通过 `dealerScope` API 将系统用户与特定的经销商或产品线进行逻辑绑定，为后端数据权限规则提供动态的上下文输入。
- **模块化组件协同**：各子模块（basedata, dealer, productLine, signing）共享精简版的字典列表接口（simple-list），并在复杂页面（如签约进度）中通过组合多个子模块的 API 实现多维度的筛选与统计展示。
