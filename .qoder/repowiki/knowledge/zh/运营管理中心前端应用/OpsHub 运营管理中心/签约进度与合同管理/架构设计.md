- **分层架构**：采用 API 层（`api/opshub/signing/index.ts`）与视图层（`views/opshub/signing/`）分离的设计，API 层封装 RESTful 接口调用，视图层负责 UI 渲染与交互逻辑。
- **组件化设计**：主页面 `index.vue` 作为容器，通过组合式 API 协调统计卡片（`StatisticsCards`）、筛选栏（`SigningFilterBar`）、数据表格（`ContractTable`）及趋势图（`SigningTrendChart`）等子组件。
- **交互模式**：采用“弹窗驱动”的交互范式，将合同创建/编辑（`ContractFormModal`）、签署发起（`SignRequestModal`）、凭证上传（`UploadSignProofModal`）等复杂操作封装为独立 Modal 组件，通过 `ref` 暴露 `open` 方法进行通信。
- **数据流**：遵循“父组件获取数据 -> 传递给展示组件”或“子组件内部请求统计数据”的混合模式，确保核心列表数据的统一管理与统计数据的独立刷新。
