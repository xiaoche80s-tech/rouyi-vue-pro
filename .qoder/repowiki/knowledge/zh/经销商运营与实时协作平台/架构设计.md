- **模块化聚合架构**：采用 `yudao-server` 作为主容器，通过 Maven 依赖注入 `opshub`（业务中台）、`im`（即时通讯）、`bpm`（工作流）及 `system`（基础服务）等模块，利用 Spring Boot 自动配置完成组件装配。
- **跨域数据权限治理**：在 `opshub` 模块内定义 `DealerDataPermissionRule`，基于用户角色（经销商/品牌方/执行员）动态生成 SQL 过滤条件（`dealer_code` / `product_line_code`），并与 `framework` 提供的 AOP 拦截器联动，实现业务数据的行级隔离。
- **实时信令与业务联动**：`im` 模块提供底层的 WebSocket 连接管理与 RTC 信令支持；`opshub` 的业务逻辑（如工单流转、订单状态变更）通过调用 `CsWebSocketService` 或发送 MQ 消息，触发前端实时 UI 更新，形成“业务动作-实时通知”的闭环。
- **标准化技术底座支撑**：所有业务模块共享 `yudao-framework` 提供的 Starter 组件（如 MyBatis Plus 增强、Redis 缓存、安全认证），确保了跨模块开发规范的一致性与基础设施能力的复用。
