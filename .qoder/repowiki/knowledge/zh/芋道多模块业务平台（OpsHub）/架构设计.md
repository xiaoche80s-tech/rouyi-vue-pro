- **模块化容器架构**：采用 Maven 多模块管理，`yudao-server` 作为唯一启动入口，通过依赖注入动态聚合 `system`、`bpm`、`im`、`opshub` 等业务模块。
- **Starter 基础设施隔离**：`yudao-framework` 封装了 MyBatis、Redis、Security 等通用技术组件为独立 Starter，实现业务逻辑与技术底座的解耦。
- **跨模块数据权限协同**：通过 `yudao-spring-boot-starter-biz-data-permission` 提供全局 AOP 拦截，支持 `system` 模块的部门维度过滤与 `opshub` 模块自定义的经销商/产品线维度过滤共存。
- **统一 API 契约通信**：模块间通过 `api` 包下的接口（如 `AdminUserApi`）进行跨域调用，避免直接引用内部 Service，确保模块边界清晰。
