- **跨模块服务契约**：通过 `api/` 包下的 `ConfigApi`、`FileApi`、`WebSocketSenderApi` 等接口，向其他业务模块暴露基础能力，实现解耦调用。
- **统一自动配置**：在 `framework/` 包下定义 `YudaoFileAutoConfiguration`、`InfraWebConfiguration` 等，利用 Spring Boot Starter 机制将文件存储、安全校验等基础设施能力自动注入到应用上下文。
- **元数据驱动开发**：以 `db_management` 获取的数据库元数据为输入，驱动 `codegen` 引擎基于 Velocity 模板批量生成符合项目规范的 CRUD 代码，形成从数据层到前端页面的完整闭环。
- **运维治理集成**：集成 Spring Boot Admin 服务端与 Quartz 调度器，并通过 `job/` 包下的清理任务（如 `AccessLogCleanJob`）实现系统日志与运行状态的自动化治理。
