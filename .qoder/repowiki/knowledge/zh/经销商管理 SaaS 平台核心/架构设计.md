- **单体模块化架构**：采用 Maven 多模块聚合模式，由 `yudao-server` 作为启动容器，按需引入 `system`（基础服务）、`infra`（基础设施）、`bpm`（工作流）、`im`（即时通讯）及 `opshub`（核心业务）模块。
- **技术底座支撑**：所有业务模块均依赖 `yudao-framework` 提供的 Spring Boot Starter（如安全、租户隔离、数据权限），确保跨模块的权限控制与数据隔离一致性。
- **前后端协同**：后端通过 RESTful API 提供服务，前端 `yudao-ui-admin-vue3` 对应各业务模块视图，并通过 WebSocket 实现咨询消息的实时精准推送。
