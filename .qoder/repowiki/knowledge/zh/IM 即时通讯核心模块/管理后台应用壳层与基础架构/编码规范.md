- Store 模块遵循“定义 Store + 导出无参获取函数”模式（如 `useUserStoreWithOut`），便于在非组件上下文中访问状态。
- 通用业务逻辑封装为 Composables（如 `useCsConsult`, `useCache`），置于 `hooks/web` 或 `hooks` 根目录，实现跨组件复用。
- 布局组件采用 TSX 编写（如 `useRenderLayout.tsx`），以利用编程式渲染能力处理复杂的多分支布局结构。
- API 请求配置通过 `config/axios` 集中管理，并在拦截器中统一处理多租户标识（tenant-id）与访问令牌（Authorization）。
