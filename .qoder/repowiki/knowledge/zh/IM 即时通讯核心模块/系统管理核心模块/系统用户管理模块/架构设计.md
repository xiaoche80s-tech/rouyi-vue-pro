- **API 层**：`src/api/system/user/` 下定义 `index.ts`（核心 CRUD）、`profile.ts`（个人中心）及 `socialUser.ts`（社交绑定），封装 Axios 请求。
- **视图层**：`src/views/system/user/index.vue` 为主入口，采用“左侧部门树 + 右侧用户表格”布局，集成搜索、分页及批量操作。
- **组件化设计**：通过 `UserForm.vue`（新增/编辑）、`UserAssignRoleForm.vue`（角色分配）、`UserImportForm.vue`（Excel 导入）实现业务逻辑解耦。
- **通用选择器**：`components/` 目录下提供 `UserSelectDialogV2.vue` 等组件，支持单选/多选模式及跨页勾选，供其他模块复用。
- **依赖方向**：视图组件依赖 API 模块获取数据，并通过 `emit` 事件与父组件通信，遵循 Vue3 Composition API 规范。
