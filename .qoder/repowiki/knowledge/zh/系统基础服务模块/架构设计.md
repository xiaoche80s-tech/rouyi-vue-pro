- **跨模块 API 契约**：在 `api` 包下定义并实现了一系列 DTO 和 API 接口（如 `AdminUserApi`, `DeptApi`, `PermissionApi`），供其他业务模块（如订单、商品模块）进行远程或本地调用，实现数据解耦。
- **统一数据访问层**：所有子功能共享底层的 `dal` 层（MyBatis Mapper 与 Redis DAO），确保用户、权限、日志等核心数据的一致性读写。
- **公共框架集成**：通过 `framework` 包将验证码、操作日志、数据权限等横切关注点以 Starter 或配置类形式注入 Spring 容器，为 Controller 层提供即插即用的安全与审计支持。
