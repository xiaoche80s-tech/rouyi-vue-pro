- **分层架构**：遵循 Controller-Service-Mapper 经典三层结构，内部通过 `AdminUserService` 和 `DeptService` 封装核心业务逻辑。
- **API 暴露**：提供 `AdminUserApi` 和 `DeptApi` 接口供模块间调用，实现跨模块的用户与组织数据查询及校验。
- **数据持久化**：基于 MyBatis-Plus，通过 `AdminUserMapper` 等接口操作 `system_users`、`system_dept` 等数据表，支持多租户隔离。
- **视图模型**：严格区分 API 传输对象 (DTO)、控制器视图对象 (VO) 与数据库实体 (DO)，并在各层间进行转换。
