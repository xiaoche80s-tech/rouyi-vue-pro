- **分层架构**：遵循 Controller-Service-DAL 标准分层。Controller (`ImRtcCallController`) 处理业务信令（创建、加入、接听等）；Service (`ImRtcCallServiceImpl`) 承载核心状态机逻辑（CREATED→RUNNING→ENDED）及 LiveKit 交互；DAL 层包含 MySQL (`ImRtcCallMapper`) 持久化通话记录与 Redis (`ImRtcCallLockRedisDAO`) 分布式锁。
- **厂商适配层**：`framework.rtc` 包封装 `LiveKitClient`，负责 JWT Token 签发（Join/Admin）、Server API 调用（DeleteRoom/ListParticipants）及 Webhook 签名校验，隔离底层 SDK 细节。
- **并发控制**：通过 `ImRtcCallLockRedisDAO` 实现基于“好友对”或“群组ID”的细粒度分布式锁，确保同一会话场景下通话创建的原子性与唯一性。
- **异步兜底机制**：`ImRtcLiveKitController` 接收 LiveKit Webhook 回调，处理成员异常退出（Participant Left）或房间结束事件，与定时任务 (`ImRtcCallCleanupJob`) 共同保障数据最终一致性。
