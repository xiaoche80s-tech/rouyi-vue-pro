- **统一推送网关**：`websocket` 子模块作为所有业务域（私聊、群聊、频道、RTC信令）的出口，通过 `ImWebSocketService` 屏蔽底层 `infra` WebSocket API 细节。
- **事务一致性保障**：采用 `TransactionSynchronizationManager` 注册 `afterCommit` 钩子，确保数据库状态变更（如消息落库、好友关系建立）提交后才触发异步推送，解决“客户端收到通知但查库无数据”的竞态问题。
- **跨域依赖治理**：强依赖 `system` 模块获取用户身份与权限上下文，依赖 `infra` 模块实现文件存储（消息素材）与 WebSocket 基础设施；内部通过 `dal` 层按业务域（friend/group/message）物理隔离数据访问。
- **实时信令集成**：`rtc` 子模块通过 `LiveKitClient` 封装第三方音视频服务，并通过 Webhook 回调与本地数据库状态（`ImRtcCallDO`）同步，实现通话状态的持久化与僵尸会话清理。
