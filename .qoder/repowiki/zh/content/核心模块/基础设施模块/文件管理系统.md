## 简介
本文件管理系统围绕"文件上传、配置管理、访问与安全、分类与元数据、生命周期与备份"展开，覆盖后端控制器、服务层、前端接口与配置模板。系统支持四种上传模式：后端直传、前端直连对象存储（预签名直传）、本地存储和Azure Blob存储。文件配置支持多存储后端（本地、FTP、SFTP、S3兼容、Azure Blob等），并通过"主配置"统一对外提供默认存储能力。前端提供文件与配置的分页、创建、删除、测试等功能。

**更新** 新增 Azure Blob 存储集成，扩展存储提供商支持，提供企业级云存储解决方案。

## 架构总览
系统采用前后端分离，文件上传支持四种模式：
- 后端直传：前端上传给后端，后端落盘或写入对象存储
- 前端直传：后端返回预签名 URL，前端直连对象存储上传，再创建文件记录
- 本地存储：文件直接存储在服务器本地磁盘
- Azure Blob存储：通过Azure Blob客户端直接上传到Azure存储

### 文件上传与直传流程
- 后端直传
  - 前端上传文件到后端，后端调用服务层保存文件并返回访问路径
- 前端直传
  - 后端生成预签名 PUT URL，前端直连对象存储上传，随后创建文件记录
- Azure Blob直传
  - 专门针对Azure Blob存储的预签名URL生成和文件上传流程

### 文件配置管理
- 支持的存储策略
  - 本地存储：通过基础路径与域名组合访问
  - FTP/SFTP：通过主机、端口、用户名、密码等配置
  - S3 兼容：通过 endpoint、bucket、region、AK/SK 等配置
  - Azure Blob：通过 endpoint、accountName、accountKey、container 等配置
  - 可扩展：新增存储类型只需在服务层扩展对应客户端
- 配置项要点
  - 主配置：用于默认存储与对外访问域名
  - 可见性：控制是否对外展示
  - 域名：用于拼接最终访问 URL
  - Azure Blob特有配置：accountName、accountKey、container、enablePublicAccess
- 测试配置：通过上传测试文件验证配置可用性

**更新** 新增 Azure Blob 存储配置支持，包含账户名、密钥、容器等专用配置项。

## 故障排除指南
- 上传失败
  - 检查对象存储凭据与域名配置
  - 使用"测试配置"接口验证连通性
  - Azure Blob：检查账户名、密钥和容器权限
- 预签名 URL 失效
  - 确认有效期参数与服务器时间同步
  - Azure Blob：检查 SAS Token 生成和权限设置
- 权限不足
  - 确认控制器权限注解与用户角色授权
  - Azure Blob：验证容器访问权限和 SAS 权限范围
